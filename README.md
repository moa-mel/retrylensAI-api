# RetryLensAI

RetryLensAI is an API reliability and retry management solution designed to help developers handle failed API requests more effectively.

It aims to reduce the impact of temporary API failures, network interruptions, and server errors by providing a centralized way to manage request retries.

Instead of implementing retry logic separately in every application, developers can integrate RetryLensAI into their projects through its API or the published npm SDK.

## Key Purpose

- **API Reliability:** Help applications recover from temporary request failures.
- **Automated Retries:** Provide a mechanism for retrying failed API requests.
- **Developer Experience:** Reduce the need to write repetitive retry-handling logic across applications.
- **Reusable Integration:** Make RetryLensAI accessible through an npm package.

## NPM SDK

RetryLensAI is also available as an npm package, allowing developers to integrate it into their Node.js applications.

**Install the SDK:**

```bash
npm install retrylensai-sdk
```

**Resources:**

- [NPM Package – retrylensai-sdk](https://www.npmjs.com/package/retrylensai-sdk)
- [GitHub Repository – RetryLensAI API](https://github.com/moa-mel/retrylensAI-api)

The RetryLensAI API provides the backend, while the npm SDK offers a convenient way for developers to integrate its functionality into their applications.
